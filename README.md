# Задачи:

### 1. Парсер .tex файлов (папка под названием **TeX-parser**):

   Консольное приложение на Python. Получает на вход файл формата .tex и проверяет, есть ли в списке литературы лишние ссылки на книги, которых нет в файле. Программа выводит количество ссылок в тексте и количество записей в библиографии. Если есть неиспользуемые ссылки, то программа выведет все записи без ссылок. Если все записи используются, то программа выдает соответствующее сообщение. Также для проверки выводит в консоль массив ссылок в тексте и массив записей в библиографии и выводит массивы неиспользуемых ссылок.


### 2. Парсер сайта Urait (папка под названием **Urait-parser**):

   Парсер скачивает информацию о всех учебниках с сайта Юрайт (раздел "Для вузов" - https://urait.ru/library/vo) и сохраняет её в формате RUSMARC. Программа умеет останавливаться и продолжать работу с того же места, не скачивая данные повторно, а также удаляет дубликаты после скачивания всех страниц. При запуске пользователь указывает, сколько страниц нужнообработать.


### 3. Парсер .tex фалов (Web-приложение на Flask) (папка под названием **TeX-parser (Flask)**): 

   Предыдущее консольное приложение из 1-го пункта было доработано. Был добавлен веб-интерфейс, реализованный с помощью Flask. Теперь работает в обе стороны: проверяет, есть ли в списке литературы лишние ссылки на книги, которых нет в файле, а также теперь проверяет есть ли в тексте ссылки на книги, которых нет в списке литературы.


### 4. Парсер .tex фалов (Web-приложение на Flask) загружен на Render: https://latex-bib-checker.onrender.com/

   Разместили приложение на бесплатном хостинге Render. При первом открытии нужно подождать 20-30 секунд, т.к. на бесплатном тарифе Render приложение "засыпает" через 15 минут бездействия.
